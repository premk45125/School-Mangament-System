# 🏫  School Management System

An interactive, high-performance web application and multi-role school management portal built for **BR GYAN DEEP SR SEC SCHOOL**, Surjanwas, Mahendragarh.

---

## 📌 Project Overview

This project serves as the official web portal and administration platform for BR GYAN DEEP SR SEC SCHOOL. It features a modern public landing page with real academic archives, topper showcases, leadership profiles, interactive student detail modals, and role-based portal routing.

### 🌟 Key Features
- **Public Portal & School Branding:** Comprehensive school details, admission inquiry routes, and campus operating hours.
- **Student Toppers Showcase:** Interactive alumni cards featuring Class 12th board toppers (Prem Kumar, Tanmay Khairwal, Satyaprakash Khairwal, Dheeraj Sharma) with modal detail popups.
- **5-Year Results Archive (2022–2026):**
  - **Class 10th:** 50 student records featuring roll numbers, father names, addresses, and scores.
  - **Class 12th:** Stream-wise records (Medical, Non-Medical, Arts, Commerce).
  - **Competitive Selections:** Historical archive for JEE Advanced (IIT Bombay, IIT Delhi, IIT Madras), NEET UG (AIIMS Delhi, AIIMS Jodhpur, AIIMS Rishikesh), and NDA Written exam.
- **Multi-Role Authentication & Dashboard Shells:** Role-tailored navigation layouts for Admin, Faculty/Teachers, Students, Parents, and Transport Incharge.
